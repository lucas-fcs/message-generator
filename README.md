# Message Generator

A simple JavaScript application that generates absurd fictional news headlines.

## Features

- Random character generation
- Random objectives
- Random problems
- Random outcomes
- Data stored in JSON
- Modular architecture using ES Modules

## Technologies

- JavaScript
- Node.js
- Git
- GitHub

## Project Structure

```txt
message-generator/
│
├── app.js
├── formatter.js
├── generator.js
├── JokeRepository.js
│
├── data/
│   └── jokes.json
│
├── package.json
└── README.md
```

## Run Locally

```bash
node app.js
```
